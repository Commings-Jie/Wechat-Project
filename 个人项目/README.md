## 📖 项目简介

**《心情天气站》** 是一款将**真实地理气象**与**个体主观心绪**深度绑定的高颜值微信小程序。

传统日记应用长篇大论、打卡门槛高难以坚持，而传统天气软件冰冷工具化。本项目创新性地提出 **“气象映射心绪”** 设计理念：
- 将喜怒哀乐具象化为 **6 种光感天气印章**，搭配 **1–5 分能量胶囊**，3 秒即可完成心绪轻量打卡；
- 整合**高德开放平台逆地理编码与天气感知**，动态映射真实天色与微气候；
- 自研**原生弹性周历网格**与 **Canvas 2D 撕纸日签小票**相册导出；
- 提供 **365 天全景像素情绪年谱** 与 **生活场景治愈榜 TOP3**；
- 基于专属印章号 **MoodID** 打造私密温情双机社交互动；
- 采用 **离线双模协同容灾机制**，断网毫秒级降级托底，重连静默增量同步。

## 🌟 核心功能一览

### 1. 首页·天晴感知与能量手账
- **高德地理逆编码**：根据设备定位实时呈现所在城市（如青岛黄岛区）、实时气温、天气现象与动态天空背景。
- **情感化统计**：实时显示当前**连续打卡天数**与**本月平均心情指数**。
- **轻量手账卡片流**：直观浏览近期心情图文卡片，支持按日期回溯与快捷补记。

### 2. 记录页·拟物印章与多维留痕
- **6 种天气印章**：晴朗、多云、阴天、细雨、暴雨、雪花，色彩与微交互深度定制。
- **1–5 分心情能量胶囊**：量化主观心境波动。
- **场景生活标签**：内置学习、美食、运动、旅行、休息、工作等多维度标签，支持多选。
- **图文多图留痕**：支持上传最多 3 张生活照片，配以心绪语录。

### 3. 日历页·周历表情与日签小票导出
- **原生弹性表情网格**：告别第三方重型库卡顿，纯原生 CSS 弹性网格毫秒级渲染周历表情。
- **Canvas 2D 离屏渲染**：生成复古撕纸风 **“心情日签小票”**（含天气印章、打卡时间、心绪语录与能量条形码），一键保存至手机系统相册。

### 4. 统计页·情绪像素年谱与治愈榜
- **365 天情绪年报像素墙**：仿 GitHub 热力图的高颜值情绪像素阵列，一眼洞悉全年心境起伏。
- **七日晴雨时钟**：环形时钟直观可视化过去一周的情绪晴雨分布。
- **生活场景治愈榜 TOP3**：统计最高能量日对应的生活标签，发现生活中的小确幸。

### 5. 社交页·专属 MoodID 与温情互动
- **专属印章号 (MoodID)**：每位用户分配独一无二的专属印章身份号。
- **双机好友互动**：支持按 MoodID 搜索好友、双向发送与通过申请。
- **好友空间动态流**：查阅好友公开的心情动态，发送温情点赞与鼓励评论，红点即时提醒。

## 🏗️ 系统架构设计

系统采用 **客户端原生 MVVM + 微信云开发 Serverless 微服务** 架构：

```
┌────────────────────────────────────────────────────────┐
│               表现层 (Client MVVM UI Layer)             │
│   pages/index    pages/calendar   pages/stats          │
│   pages/record   pages/friends    pages/my             │
│   components/navigation-bar       components/loading   │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│                 逻辑与容灾缓存层 (Logic & Cache)          │
│    utils/mood.js (气象映射算法)                          │
│    utils/cloud.js (双模熔断与数据清洗 cleanRecord)        │
│    LocalStorage (离线数据池 / 本地托底)                 │
└──────────────┬──────────────────────────┬──────────────┘
               │ 联网同步                 │ 定位/天气
┌──────────────▼─────────────┐ ┌──────────▼──────────────┐
│  微信云开发 Serverless 后端 │ │   外部第三方开放平台   │
│  ├── 云函数 (login/records/│ │  ├── 高德逆地理编码 API │
│  │           social/weather│ │  └── Open-Meteo 天气    │
│  ├── 云数据库 (NoSQL 6集合)│ └─────────────────────────┘
│  └── 云存储 (图片资源池)   │
└────────────────────────────┘
```

### 离线双模容灾与安全性
1. **云端优先，本地托底**：网络正常时自动漫游多设备；网络中断时系统毫秒级降级至本地 LocalStorage，打卡零延迟、界面零卡顿。
2. **静默增量同步与数据清洗**：网络恢复后，通过 `records.sync` 云函数进行增量合并，并自动清洗过滤历史测试脏数据。
3. **数据安全闭环**：云数据库集合权限全量锁定为“仅管理端可读写”，前端无法直接越权操作，所有业务逻辑均由云函数强制校验真实的微信底层 OpenID。

## 🚀 快速上手与运行部署

### 1. 环境准备
- 微信开发者工具（Stable 最新版）
- 微信 AppID 与微信云开发环境

### 2. 导入与运行
1. 打开微信开发者工具，点击 **“导入项目”**；
2. 选择本工程根目录，填入您的微信小程序 **AppID**；
3. 点击 **“确定”** 即可在模拟器中即时编译与预览。

### 3. 云开发后端配置（可选·支持无云离线模式）
本小程序具有**离线双模容灾**能力。若不配置云端，系统将自动以纯本地缓存模式流畅运行；若需体验云漫游与双机社交，请按以下步骤配置：
1. 打开开发者工具顶部 **“云开发”** 控制台，创建环境（如 `cloud1-xxxx`）；
2. 在数据库中新建以下 6 个集合，权限均设置为 **“仅管理端可读写”**：
   - `users`（用户资料与 MoodID）
   - `records`（心情记录主表）
   - `friendRequests`（好友申请流）
   - `friendships`（双向好友关系）
   - `likes`（点赞记录）
   - `comments`（动态评论）
3. 在 `cloudfunctions/` 目录下，分别右键 `login`、`records`、`social`、`weather` 文件夹，选择 **“上传并部署：云端安装依赖（不上传 node_modules）”**；
4. 重新编译小程序，首页提示“云端已连接”即完成全栈部署。
