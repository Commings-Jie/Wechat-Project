## 🏆 期末个人项目：心情天气站 (Mood Weather Station)

> **目录指引**：[进入个人项目目录](./个人项目/) &nbsp;|&nbsp; [查看项目完整文档](./个人项目/README.md)

### 1. 项目简介与设计理念
**《心情天气站》** 是一款将**真实地理气象**与**个体主观心绪**深度绑定的高颜值微信小程序。针对传统心理手账记录门槛高、难以坚持的痛点，创新性提出“气象映射心绪”：
- **心绪具象化**：6 种光感拟物天气印章 + 1~5 分能量胶囊，3 秒完成心绪轻量留痕；
- **气象感知**：整合高德开放平台地理逆编码与天气微气象，动态映射天空背景与生活关怀；
- **自研周历表情网格**：告别第三方重型库卡顿，原生 CSS 弹性网格毫秒级渲染；
- **Canvas 2D 日签小票**：离屏渲染复古撕纸风“心情小票”，一键保存至手机系统相册；
- **365 天情绪年报像素墙**：类 GitHub 提交热力图的高颜值像素阵列，统计生活场景治愈榜 TOP3；
- **MoodID 私密社交**：基于专属印章号的双机好友申请、动态流与温情点赞互动；
- **离线双模容灾**：网络正常时云端漫游，断网毫秒级降级至 LocalStorage 本地托底，重连增量同步并清洗历史测试脏数据。
